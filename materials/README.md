# 素材索引

图片已按内容重命名，并按用途归入以下一级目录。原先具有中文业务含义的文件名已沿用；原先使用相机编号的文件改为中文内容名。

| 目录 | 内容 |
| --- | --- |
| `住宿/` | 合院、客房、卫浴及住宿空间 |
| `建筑/` | 博物苑、戏楼、建筑外观、屋顶与门窗细节 |
| `文化体验/` | 桃源绣、擂茶、书屋、茶空间与竹艺空间 |
| `餐饮/` | 餐厅、宴席与菜品 |
| `体验活动/` | 泛舟等体验活动 |
| `农事/` | 茶田、菜园、果园及农事画面 |
| `食材制作/` | 食材晾晒与擂茶制作过程 |
| `自然风光/` | 航拍、山水、竹林、园林、湖泊与步道 |
| `服务空间/` | 接待厅、会议与水疗空间 |
| `动物/` | 鸟类、鸡鸭等动物素材 |
| `村居生活/` | 村民生活与到访场景 |
| `归档/历史-上传素材/` | 原历史上传素材，仍保留全部文件；其中人像、插画和班级图形与正式项目素材隔离存放 |

文件名和分类目录均使用中文；同一主题的多张图以两位序号区分。`审计记录/rename-map.csv` 与 `审计记录/rename-map-chinese.csv` 保留本次两轮调整的完整映射。
